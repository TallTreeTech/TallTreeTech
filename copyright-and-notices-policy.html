Purpose

This policy establishes standards for copyright protection, legal notices, and intellectual property acknowledgment across all TallTree Technologies deliverables, software products, documentation, and client work. It ensures proper attribution, legal compliance, and protection of both company and third-party intellectual property rights.

1. Copyright Ownership

1.1 Company Work Product

All work product created by TallTree Technologies employees, contractors, and consultants in the course of their employment or engagement is owned exclusively by Software Systems Limited trading as TallTree Technologies, unless otherwise agreed in writing.

Work product includes:

  • Source code and compiled software
  • Technical documentation and specifications
  • Design documents and architecture diagrams
  • API documentation and integration guides
  • User manuals and training materials
  • Marketing materials and website content
  • Research and development outputs
  • Data models and database schemas
  • Test plans and quality assurance documentation
  • Configuration files and deployment scripts

1.2 Employee and Contractor IP Assignment

All employees and contractors must sign an IP Assignment Agreement as part of their employment or engagement contract, explicitly assigning all intellectual property rights to the company.

Reference: Employee NDA and IP Assignment Agreement (employee-nda-ip-assignment.html)

1.3 Client Work Copyright Transfer

Unless otherwise specified in the Master Services Agreement or Statement of Work, copyright in bespoke software developed specifically for clients transfers to the client upon full payment.

Standard copyright transfer provisions:

  • Bespoke Development: Copyright transfers to client upon final payment
  • Pre-existing IP: TallTree Technologies retains ownership of frameworks, libraries, and tools
  • Reusable Components: Client receives perpetual license; TallTree retains ownership
  • Open Source Components: Subject to original open source license terms
  • Third-party Components: Client receives sublicense rights only
Important: All copyright transfer must be documented in the Statement of Work or project acceptance certificate.

3. Open Source Attribution Requirements

3.1 Open Source License Compliance

TallTree Technologies strictly complies with all open source license obligations. All projects using open source components must maintain accurate attribution and license compliance.

Attribution Requirements:

  • Maintain NOTICE Files: All open source attributions must be listed in a NOTICE.txt or LICENSES.txt file
  • Preserve Copyright Notices: Original copyright notices in open source code must never be removed or modified
  • Include License Texts: Full license text must be included for all open source dependencies
  • Document Modifications: Any modifications to open source code must be documented per license requirements

3.2 Third-Party Dependencies

All projects must maintain a DEPENDENCIES.md or automated dependency tracking file listing:

  • Component name and version
  • License type (e.g., MIT, Apache 2.0, GPL)
  • Copyright holder
  • Link to project homepage
  • Link to license text

4. Third-Party Intellectual Property Acknowledgment

5. Trademark Usage

5.1 TallTree Technologies Trademark

The name "TallTree Technologies" and associated logos are trademarks of Software Systems Limited.

Trademark Usage Guidelines:

  • Use TallTree Technologies® (with registered trademark symbol) in formal documents
  • Use title case: "TallTree Technologies" (not "talltree technologies" or "TALLTREE TECHNOLOGIES")
  • Do not abbreviate to "TallTree" or "TT" in legal documents
  • Do not use as a verb or generic term
  • Include trademark attribution in marketing materials: "TallTree Technologies is a registered trademark of Software Systems Limited"

5.2 Third-Party Trademarks

When referencing third-party products, services, or technologies:

  • Use correct trademark symbols (™, ®) on first mention
  • Use correct spelling and capitalization
  • Include trademark attribution: "All trademarks are the property of their respective owners"
  • Do not imply endorsement or partnership without written authorization

9. Copyright Registration and Protection

9.1 Copyright Registration

While copyright exists automatically upon creation, TallTree Technologies may register significant works with the UK Intellectual Property Office (IPO) for enhanced protection.

Works suitable for registration:

  • Major software products and platforms
  • Proprietary frameworks and libraries
  • Significant technical publications
  • Training course materials

9.2 Copyright Enforcement

Upon discovery of copyright infringement:

  1. Document the infringement with screenshots and evidence
  2. Send cease and desist notice to infringing party
  3. Issue DMCA takedown notice if applicable (online infringement)
  4. Escalate to legal counsel if infringement continues
  5. Consider civil action for significant commercial harm
