## Usage Guidelines

**For New Clients:**
1. Send NDA first for initial discussions
2. Execute MSA once relationship is established
3. Use simple SOW for each project (references MSA)
4. Use Proposal template for complex/competitive bids
5. Use Quote template for straightforward pricing

**For Employees:**
1. Employment contract at hiring
2. Employee NDA signed concurrently
3. Provide employee handbook during onboarding
4. Reference specific policies as needed

**For Operations:**
1. Use templates consistently across all projects
2. Maintain document version control
3. Review and update annually
4. Ensure all staff trained on relevant policies
