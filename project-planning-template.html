12. Change Management

12.1 Change Control Process

  1. Change Request Submission: Any stakeholder may submit a change request using the change request form
  2. Impact Assessment: PM assesses impact on scope, schedule, budget, and quality (within 3 working days)
  3. Review: Change Control Board reviews the change request and impact assessment
  4. Decision: CCB approves, rejects, or defers the change request
  5. Implementation: If approved, change is planned and implemented according to updated schedule
  6. Communication: All stakeholders notified of change decision and impacts
